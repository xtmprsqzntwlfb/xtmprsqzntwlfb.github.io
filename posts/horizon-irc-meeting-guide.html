Leading the OpenStack Horizon Weekly IRC Meeting

July 27, 2026

Preparation

Update the Agenda Etherpad: Update agenda sections for the upcoming meeting on the Etherpad (ideally 24 hours in advance):

  • Review the OpenStack Mailing List to identify any Horizon-related announcements
  • Monitor progress on release priority tasks
  • Confirm that all recent bug reports have been added: Horizon bugs on Launchpad
  • Check if there's On-Demand Agenda added and plan the meeting correspondingly

Ping the Team: Drop a reminder before the meeting starts (ideally 15 minutes in advance)

Step-by-Step Meeting Execution (IRC Commands & Dialogue)

Copy and paste these exact MeetBot commands and dialogue flow into #openstack-horizon.

Call to Order & Roll Call (Minutes 0-5)

#startmeeting horizon
  • Start exactly on time. Use the MeetBot commands to log the session
  • Welcomes, introductions, and a quick roll call
  • Agenda: https://etherpad.opendev.org/p/horizon-release-priorities#L39
  • Wait 1-2 minutes for team members to type

Notices (Minutes 5-10)

#topic Notices
  • Schedule reminder:
    - This week is R-N week
    - Hibiscus Release Schedule: https://releases.openstack.org/hibiscus/schedule.html
  • Horizon-related and global announcements from OpenStack Mailing List

Release priorities (Minutes 10-20)

#topic Release priorities
  • Focus on the current release cycle priorities
  • Discuss the status of high-priority tasks: are they done, in progress or blocked
  • Identify any strict deadline blockers (e.g., Feature Freeze approaching)
  • If the patch is ready, say it explicitly, asking the team to review
  • If the patch is WIP, ask for any status update from the author

Bug deputy report (Minutes 20-30)

#topic Bug deputy report
  • Review newly reported bugs or security issues
  • If Horizon check/gate queues are broken, find a volunteer to investigate the CI

Open reviews (Minutes 30-40)

#topic Open reviews
  • Point out the patches waiting for review
  • Contributors are welcome to discuss their patches on review

On-demand agenda (Minutes 40-50)

#topic On-demand agenda
  • Contributors can submit topics beforehand, or the PTL may include follow-ups from earlier debates
  • This space also welcomes members of other teams to address cross-project concerns

Open discussion (Minutes 50-60)

#topic Open discussion
  • Open the floor for any other discussion
  • Contributors can use this space to initiate discussions or introduce community events

Wrap up (Minutes 60)

  • Thank everyone for joining the meeting
#endmeeting
  • MeetBot will automatically output links to the HTML summary and .log.html file

Post-Meeting Wrap Up

Verify MeetBot log output:

  • Click the meetings.opendev.org link generated by #endmeeting to confirm that all the tags were captured properly

Update the Etherpad:

  • Clear the active agenda area (line 39) and create the header for the next meeting date

Pro-Tips for the Chair

  • Use Meetbot Commands: if needed, use #info, #link, and #action to make the auto-generated meeting minutes easier to read afterward.
  • Manage the Silence: IRC has lag. After asking a question, explicitly state: "Waiting one minute for responses" to give people time to type long thoughts.
  • Take It Offline: If developers get into a deep architecture debate, politely intervene and suggest taking it to a dedicated Etherpad or the Mailing List to keep the meeting moving.
